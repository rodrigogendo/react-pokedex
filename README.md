# React Pokédex

## GitHub Pages

[Open the deployed Pokédex](https://rodrigogendo.github.io/react-pokedex/)

## About

A Pokédex web app for browsing Pokémon, viewing their details and forms, and searching by name or type.

## Built With

- React 19
- TypeScript
- Vite
- Tailwind CSS
- PokéAPI

## Development

```bash
npm install
npm run dev
```

Run tests with `npm test` and create a production build with `npm run build`.
